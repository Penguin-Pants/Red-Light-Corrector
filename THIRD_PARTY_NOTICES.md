# Third-party notices

Local packaging retrieves the unmodified classic embedded WASM artifact from libheif-js 1.23.5. The build verifies the package and artifact hashes. The offline package keeps the artifact separate from the application worker so it can be replaced and rebuilt. The package includes the upstream license texts. Keep the exact archive and notices with any copy intended for redistribution and review the corresponding-source and codec obligations before publishing binaries.
